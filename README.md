# Curario – Downloads

Dieses Repository dient ausschließlich der Verteilung veröffentlichter Windows-Installer für Curario. Der Quellcode wird separat in einem privaten Repository verwaltet und ist hier nicht enthalten.

## Aktueller Stand

Freigegebene Versionen findest du unter **Releases**; die neueste ist als „Latest“ markiert. Nur dort veröffentlichte Installer sind für den Einsatz freigegeben. Eine Versionsnummer oder ein lokal erstellter Build allein bedeutet keine Freigabe.

## Downloads und Updates

Jedes Release enthält den Windows-Installer (`Curario-Setup-<Version>.exe`) und die zugehörigen signierten Update-Metadaten (`.exe.json`), über die bestehende Installationen automatisch aktualisiert werden. Bitte beachte die Versionshinweise des jeweiligen Releases und verwende ausschließlich freigegebene Versionen.

Die Update-Verteilung verwendet kryptografisch signierte Update-Metadaten und Prüfsummen. Kompatible Curario-Versionen prüfen diese vor der Installation eines Updates. Diese Prüfung ist nicht mit einer Windows-Authenticode-Signatur gleichzusetzen.
