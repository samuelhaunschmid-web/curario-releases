# Curario – Downloads

Dieses Repository dient ausschließlich der Verteilung veröffentlichter Windows-Installer für Curario. Der Quellcode wird separat in einem privaten Repository verwaltet und ist hier nicht enthalten.

## Aktueller Stand

Dieses Download-Repository wird eingerichtet. Aktuell ist hier noch kein freigegebener Installer veröffentlicht. Eine vorhandene Versionsnummer oder ein lokal erstellter Build bedeutet nicht, dass die betreffende Version bereits für den Einsatz freigegeben ist.

## Downloads und Updates

Freigegebene Installer werden künftig unter **Releases** in diesem Repository angeboten. Bitte beachte die Versionshinweise des jeweiligen Releases und verwende ausschließlich freigegebene Versionen.

Die vorgesehene Update-Verteilung verwendet kryptografisch signierte Update-Metadaten und Prüfsummen. Kompatible Curario-Versionen prüfen diese vor der Installation eines Updates. Diese Prüfung ist nicht mit einer Windows-Authenticode-Signatur gleichzusetzen.

## Nutzung und Berechtigungen

Dieses Repository und künftig veröffentlichte Installer sind öffentlich zugänglich. Der Download oder die Installation erteilt keine Nutzungslizenz und gewährt keinen Zugriff auf Organisations- oder Kundendaten.
